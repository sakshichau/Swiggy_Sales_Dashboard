** 📊 SWIGGY SALES DASHBOARD **
 
 📌 Project Overview
Comprehensive sales analysis project built in Excel to evaluate Swiggy’s performance data. The dashboard highlights KPIs, revenue trends, and customer insights, enabling data‑driven decision making.

🔑 Key Deliverables
- Interactive Dashboard with charts, slicers, and filters for dynamic reporting

- Data Cleaning and transformation using Power Query

- Automated Reporting through Pivot Tables and Macros

- Business Insights: top products, revenue growth, and customer segmentation.
  
🛠️ Tools & Technologies
- Advanced Excel (Pivot Tables, Power Query, Macros)

- SQL for data querying and aggregation

- GitHub for version control and portfolio presentation

📈 Impact
- Reduced manual reporting effort by automating workflows

- Improved accuracy and consistency of MIS reports

- Delivered actionable insights for management review

🚀 How to Access
- Clone or download the repository.

- Open the Excel dashboard file.

- Explore KPIs and charts for insights.
